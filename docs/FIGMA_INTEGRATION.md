# Integración con Figma

El prototipo web final vive en:

```text
https://TU-SERVICIO.onrender.com/app
```

En Figma puedes configurar un botón con:

`On tap → Open link → https://TU-SERVICIO.onrender.com/app`

Para abrir directamente WhatsApp usa:

```text
https://wa.me/51XXXXXXXXX?text=Hola%2C%20vengo%20de%20D%27Lorgia%20Orienta.
```

La aplicación web también incluye botones que construyen automáticamente el mensaje con el tratamiento seleccionado. Para que abran el bot, configura `PUBLIC_BOT_NUMBER` en Render.
